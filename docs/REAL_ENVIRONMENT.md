## 先说结论：钱不是瓶颈，人和账号是

跑一遍真实内容生产的钱，少到不值得开会讨论：

| 项 | 量 | 估算 |
|---|---|---|
| LLM 全量生成 HSK1 | 48 concept × 1 次调用 | **≈ $0.20**（gpt-4.1-mini 档）；旗舰档 ≈ $1.26 |
| 同上，反复重跑 5 次 | | ≈ $1.01 / $6.30 |
| TTS 合成 HSK1 全部音频 | 1296 段、约 1.6 万字符 | **≈ $0.25** |
| Azure 发音评测验证 | M0-1 的样本量 | 免费层（5 小时/月）内 ≈ **$0** |

> 算法：输入约 500 token、输出约 2500 token/concept（拼音和高棉文都很吃 token），
> 按公开单价直算。Batch API 还能再打对折。TTS 按 $16/百万字符。
> 这些是数量级判断，不是报价。

**真正的瓶颈有三个**：ABA 商户资质（走公司与银行流程，最慢）、
高棉语母语者（M0-2 盲评、M1 抽检、km 文案是同一个人能干的三件事）、
以及一批真实的初学者录音（M0-1 没有它就无法校准及格线）。

> 这一节只讲依赖与顺序；真要派活时打开那一份。

#### ① 界面文案：怎么交出去，怎么收回来

```bash
make i18n-export            # 生成 locales/km.todo.csv，30 行
# 把 CSV 发给译者，只填 translation 一列
make i18n-apply FILE=locales/km.todo.csv
```

CSV 里每行带四样东西：key、英文原文、**这句话里必须保留的 `{参数}`**、以及它在代码里被用到的位置
（`attempts.py:96` 这种，让译者能判断这是按钮还是一句话）。

回填时有四道拒绝（D-102）：**丢了 `{参数}` 的译文不收**（它会在学习者面前抛错，而且只在一种语言下发生）；
**没写成高棉文的不收**（留着英文看起来像翻完了，而这正是占位符机制要防的事）；
**把 `[[km:...]]` 占位符原样抄回来的不收**；**`key` 不存在的不收**（那一列被改过了）。
被拒的行不进系统，其余照常应用——一张只填了一半的表是正常的，不算错误。

`zh.json` 同样是 30 条待译，`make i18n-export LOCALE=zh` 导出。

#### 要告诉译者的话

> 这是一个教柬埔寨人说中文的 Telegram 机器人的界面文字，一共 30 句。
> 只填 `translation` 一列，其余别动。
> 带大括号的东西（例如 `{resets_at}`）是程序填进去的变量，**必须原样保留**，位置可以按高棉语语序调整。
> 语气：对成年初学者说话，简洁、鼓励，不要过分热情。
> 有一条特别重要：`avatar.ai_disclaimer` 必须让人明确知道讲解来自 AI 助教，不是真人老师。

#### ② 和 ③ 的交付与验收

| | 交付物 | 验收 |
|---|---|---|
| ② 盲评 | 自然度 / 可懂度各 1–5 分的打分表，≥2 人独立评 | 两项均值 ≥ 4，无致命发音错误 |
| ③ 抽检 | 填好 `verdict`（`ok` / `awkward` / `wrong`）与 `comment` 的 CSV（`make review` 导出） | 合格率 ≥ 90% |

**额外价值**：他是**唯一**能发现 HSK1 词表里「形近且同音同调」转录错误的人（D-092）——
三道机械检查都看不见这一类，请把它列为抽检时的优先项。
